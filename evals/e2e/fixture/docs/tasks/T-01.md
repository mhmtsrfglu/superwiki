## Goal

A caller can show the item list page by page. `paginate(items, size)` in `src/paginate.mjs` splits a list into pages of `size`; the last page holds whatever remains, so no item is dropped and no page is empty.

## Done when

- `paginate(items, size)` returns the items in pages of `size`, the last page holding what remains. (test)
- `npm test` passes.

## Notes

- 2026-10-06, decided with the user: `size` is a positive integer; the caller validates it.
