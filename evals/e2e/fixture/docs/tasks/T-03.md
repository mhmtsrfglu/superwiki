## Goal

A second program can read the item list without importing it. `node src/server.mjs` starts an HTTP server on port 4173 that answers `GET /items?n=<count>` with `items(count)` as JSON.

## Done when

- `node src/server.mjs` listens on port 4173 and `GET /items?n=5` answers `items(5)` as JSON.
- `npm test` passes.

## Notes

- 2026-10-06, decided with the user: `n` is read from the query string; a missing or bad `n` is answered with status 400.
