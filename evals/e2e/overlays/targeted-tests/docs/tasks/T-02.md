## Goal

A spreadsheet user can take the item list with them. `toCsv(items)` renders the list as CSV: a header line `item`, then one line per item, so a file written from it opens as one column.

## Done when

- `src/export.mjs` exports `toCsv(items)` as a named export: the header line `item`, then one line per item (test)
- An empty list gives the header line only (test)
- A value that holds a comma or a double quote is written double-quoted, with an inner quote doubled
- `npm test` passes

## Notes
