# Eval results

One row per run of an eval, newest last. [README.md](README.md) says how to run each eval and how to fill a row.

Every row up to and including the T-03 rows was measured on the Turkish originals of the inputs, in appendices A and B of [the audit source](../docs/raw/2026-10-05-prompt-quality-audit.md). The inputs in this folder are English translations, so the first run on the English set is a new baseline, not directly comparable with these rows.

Skill names are written as they are today, `sw-<name>`. Rows before the T-14 rows measured the same skills under their names of the time, a hyphen prefix in place of the `sw:` namespace, and six of them have been renamed since: do → plan-implement, run → autopilot, summarize → verify, stats → usage, board → index, visualize → view. The T-14 rows are the first on the new names and descriptions; they measured `do` under the name `complete`, which the rows after them replaced with `plan-implement` the same day.
