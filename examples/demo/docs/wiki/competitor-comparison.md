# Competitor comparison

Three fictional apps, compared against what the [[home-cook-persona]] needs.

| | Spoonful | PantryPal | Simmer |
| --- | --- | --- | --- |
| Offline recipes | Paid tier only | No | Yes |
| Search by ingredient | Title only | Tags | Title only |
| Cook mode | Yes | No | Yes |
| Sign-in | Password | Password | Social login |
| Share preview | Generic logo | Photo | Photo and title |

## Where the gap is
1. Nobody combines free offline access with a real cook mode.
2. Ingredient search is weak everywhere, which is why [[search-engine-choice]] puts it first.
3. Share previews are an afterthought in two of three.

This analysis set the scope of milestone M1 (read, cook, share) and pushed import ([[W-03]]) later.
